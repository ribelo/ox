# `('a, 'err) result` is the error channel; Cause is computed at scope boundaries

Typed failures are the `Error` side of `result`, named by polymorphic variants so unions compose by inference. Exceptions are defects. `Scope.run` catches at a scope boundary and classifies into the Cause tree (typed failure, defect, interruption with identity, finalizer failure, compositions), which is the one v1 idea kept whole. Jane Street's `handled_effect` — typed failures as `local` handler values, effect-safe by the mode system — is the serious alternative and is deferred, not rejected: on 2026-09-26 every published `ppxlib_ast+ox` requires `ocaml < 5.3.0`, so `handled_effect`, `ppx_template` and `base` cannot be installed on the 5.4.0+ox compiler this kernel targets. Revisit when the OxCaml opam repository publishes a `ppxlib_ast` for 5.3+; the spike brief is in the v1 checkout under `.scratch/research/handled-effect-errors/`.
