# The third-party packages the specs name are admitted

ADR-0005 limits dependencies to the standard library, Eio, installable Jane Street packages and unavoidable C bindings, and requires an ADR for anything else. The first specs name four packages outside that set, each as the dependency ceiling of the package that uses it: `yojson` (`ox_json`, `eta_schema_yojson`; the wire format Leash's protocol and CDP speak, and the library v1's codecs were written against), `toml` (`ox_app`; the config file format), `cmdliner` (`ox_app`; the Door's command line), and `alcotest` (tests only, and `ox_test`). Each is the de-facto OCaml choice, installs on 5.4.0+ox in the dev shell today, and has no Stdlib or Jane Street replacement that is installable on our compiler (ADR-0005's note: the ppx stack is not). They are admitted for exactly those packages; any other package that wants one of them still cites a consumer story, and any further third-party package still needs its own ADR. Row 15 (`ppx-on-oxcaml`, nppx-d10y) admits one more, as the dependency ceiling of the `ppx_yojson_minimal` package only: `ocaml-compiler-libs` v0.17.0+ox from the OxCaml opam repository (the repackaged parser, parsetree and lexer of the running 5.4.0+ox compiler; build-time only — the emitted converters refer to `Yojson.Safe` alone). It is what a `[@@deriving yojson]` preprocessor can be built on now that no ppxlib installs on this compiler: the tree it reads is by construction the tree this compiler parses, so no AST port exists to rot. Row 87 extends that admission to `ox_lint`, with `ocaml-compiler-libs` as a build-time-only dependency for the same compiler-matched parser and typed lint decider; no runtime package depends on it (^nlint-r01u, ^nlint-hxar). Packages that appear in Eio's own public interface — `mtime`, the type of `Eio.Time.Mono`, and `cstruct`, the byte buffer of `Eio.Flow` used by the HTTP client (^nhttp-6c3d) — are part of Eio for this policy and may be named wherever that interface is used (`ox_observability` measures span elapsed time on the monotonic clock, nobs-xovg). Row 16 (`remove-eta-schema`, ^nnoschema-ifg0 and ^napp-deps) moves `yojson`'s admission: `eta_schema_yojson`'s entry goes with the package, and `ox_observability` (`Redact.t`'s `yojson_of_t`/`t_of_yojson`, so a secret is redacted by being of the type a derived record names) and `ox_app` (the derived config codec and `config check`'s rendering) take it in its place.

Row 48 (`caps`, ^ncaps-iirv) decides the other way for ocaml-caps (Yoann Padioleau's capability library, OCaml Workshop 2026): Ox owns a copy of the idea in `ox_caps` rather than depending on it. The library is about two hundred lines of types and one-line wrappers, it has a single maintainer upstream, and owning it lets the capability set line up with Eio's values — `net`, `fs`, `process_mgr`, `clock` stay Eio values and `ox_caps` covers only what Eio does not hand out — and lets the Door (`Ox_app`) be the one place a powerbox is minted. Semgrep is a development tool of the gate (in the dev shells of ox and Leash), not a dependency of any package.
