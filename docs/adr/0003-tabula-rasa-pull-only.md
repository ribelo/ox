# Tabula rasa: nothing exists until a consumer pulls it; pure codecs are copied, effectful code is rewritten

eta-next started as an empty tree next to a 124k-line v1. A package, module or function enters only when a consumer's spec (to-spec format, in the consumer's repository) has a user story citing the need, and the change cites that story ID. Pure protocol code from v1 — HPACK, HTTP/1 parsing, HTTP/2 frames, WebSocket framing, the SQL DSL, AI wire types, TLS stubs — is copied file by file at the moment it is pulled; it embodies months of research and contains no `Effect.t`. Everything that mentions `Effect.t` is rewritten in direct style. The allowed set is core, observability with the OTel exporter, HTTP (h1, h2, WebSocket, TLS, router/service), AI (shared core and OpenRouter), schema and JSON, test on `Eio_mock`, app, SQL, and par with blocking as its substrate; `ox_stream` is allowed but absent until a consumer needs more than `Eio.Stream` and `Seq`. Everything else stays on `v1` for its consumer. The reason is recorded in `docs/why-ox.md` §2: v1's size was produced by a process that could write a package faster than a consumer could need it.
