# OxCaml-first, and a strict dependency policy

Eta targets OxCaml exactly (`conf-eta-oxcaml`), and uses OxCaml features wherever they earn a concrete guarantee or measurable speed — modes for non-escaping closures and cross-domain safety, unboxed types where allocation matters — decided proactively at design time, not after a problem appears; never for their own sake. Dependencies are limited to the OCaml standard library, Eio, packages from the OxCaml opam repository (Jane Street) when they are installable on our compiler, and the C bindings we cannot avoid (OpenSSL, SQLite); anything else requires an ADR. Within that, the kernel is Stdlib-first: Eio's idiom is the standard library's, and Base at every Eio seam would be friction no consumer asked for; Jane Street libraries are used as leaves (ppx derivers, `handled_effect` when installable, Incremental if ever) rather than as a replacement standard library. Note recorded on 2026-09-26: the public OxCaml repository's ppx stack supports only `ocaml < 5.3.0`, so on 5.4.0+ox no ppx-dependent Jane Street package is installable yet; the policy stands, its Jane Street clause is currently empty in practice.
