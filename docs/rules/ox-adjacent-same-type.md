# ox-adjacent-same-type

Label ordered same-type path or interval endpoints: for example ~src/~dst,
~start/~stop or ~low/~high. This rule uses the finite observed role vocabulary
in the [specification](<../issues/ox-safety-gate/22-adjacent-endpoints.md>).

It does not ban all adjacent same-type parameters, Stdlib offset/length
conventions, distinct semantic units or commutative operands. The manually
classified sample was 11/40 (27.5%), not eleven demonstrated defects.
