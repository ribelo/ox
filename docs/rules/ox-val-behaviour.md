# ox-val-behaviour

A typed, selected interface value must have period-terminated Suspension, Cancellation, Finalizers and Locking sentences. Follow the [interface documentation contract](interface-documentation.md) for exact shapes, type families and module-default precedence. ^nlintd-von6 ^nlintd-z5p5 ^nlintd-4ja0 ^nlintd-6abn

The rule checks the sentence shape **and implementation evidence**. A finite typed call graph follows local definitions, aliases and sibling compilation units in the same package. Reachable Eio waits/checks contradict “never suspends”, “not a cancellation point” and “adds no Eio operation/check” claims. Reachable explicit raises must be mentioned; an unattested `@raise E` also fails. Constructor-specific handlers remove caught exceptions; cancellation masking does not hide explicit raises. ^nlintd-truth ^nlintd-raises

External opaque calls, callback parameters, dynamic re-raises and unsupported functor evidence produce named **undecided** diagnostics unless a relevant sentence explicitly bounds that dependency. A locking-only delegation cannot qualify an unconditional suspension/cancellation claim. Missing or stale implementation evidence is undecided and fatal under `--require-typed`. Tests are still required for behaviour beyond the finite evidence model.

Typed evidence: [violating](../../test/lint/violating/val_behaviour.mli), [clean](../../test/lint/clean/val_behaviour.mli), [regression assertions](../../test/lint/test_interface_docs.ml). Truth mutations: [clean implementation](../../test/lint/clean/docs_truth.ml), [violating implementation](../../test/lint/violating/docs_truth.ml), [direct assertions](../../test/lint/test_documentation_truth.ml). Build implementations and interfaces first; missing fresh compiler evidence is undecided, not exempt.
