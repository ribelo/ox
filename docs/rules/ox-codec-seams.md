# ox-codec-seams

A finite published-domain representation and construction-evidence gate.
^safe-1kqm ^safe-gm8y ^safe-l2jj

## Designation is not a name heuristic

The audited table designates the full URL and redacting-representation interfaces,
Header's private name/value positions, Meter's histogram configuration positions,
and Logger's limit positions. It does **not** designate all interfaces, every type
called Json, all Header values, arbitrary durations, or all protocol records.
Header's transparent list representation is not claimed to validate a header set.
Redact establishes a redacting representation, not credential/content validity.

An authored interface can add enforcement with exactly one payload-free floating
attribute per signature:

```ocaml
[@@@ox.domain]
```

The marker applies to its interface-local signature, including nested public
signatures and callback definitions. Raw positions do not become safe because
an argument is labeled, a codec is called decode, or a module is called Json.
Source attributes are checked as well as typed attributes: attached attributes,
implementation-only markers, payloads and duplicates are nonwaivable undecided;
a marker removed by preprocessing has no matching typed proof and fails closed.
The marker grants **no** trusted-codec permission and never removes enforcement.

## Established construction contracts

The fixed construction table covers URL parse/of_string and validated query
rebuilding, checked Header name/value/pair, finite strictly increasing histogram
boundaries, positive logger limits, and Redact's constructor/string decoder.
It uses genuine compiler-resolved type/value/field/constructor identities, not
spelling or an abstract wrapper alone. A required provider implementation must be
present and linked to its CMI by its self-import fingerprint; all recorded imported
CMI fingerprints must still match. The audited emitted-source digest and source
ownership must match too. Five PPX bodies (SystemOne Types, Chat Types, and OpenRouter Responses/Audio/Embeddings)
are pinned to the reviewed emitted inputs, not their different authored hashes.
Their generated decoder results resolve to Stdlib.result even beside a local result
type. The review includes required-field/type failures, optional and extra-field
policies, nested decoder error propagation, and the manually narrowed Audio,
Embeddings and Responses outputs. Internal raw passthrough remains protocol
ownership, not evidence of domain validation; no declaration gains permission.
Byte-identical preprocessing copies are accepted. Additional compiler-side
preprocessing is unresolved evidence, never inferred semantic validation.

These are finite audited source contracts, **not** a general semantic proof engine,
cryptographic package authentication, or protection against forged compiler
metadata/toolchains. Source edits, changed transforms, missing/stale provider CMTs,
and changed imports require rebuilding/re-auditing rather than trusting identity.
Installed consumers use genuine provider CMIs/CMTs without provider checkout sources.

## Traversal and decisions

Compiled public signatures, nested modules/module types, expanded includes,
resolved signature aliases, arrows (including callback arguments/results), tuples,
records, variants, polymorphic variants, object rows and container arguments are
walked. Declaration parameters are substituted into aliases and payloads before
checking. Recursion is guarded by compiler type/path identity; arguments are still
checked before a path cycle is cut. Transparent aliases do not establish a new
construction obligation. Opaque **produced** positions without a finite validated
construction contract are undecided, not a clean proof based on abstraction.

An actual raw Yojson.Safe/Basic/Raw or Obj representation in an enforced published
position is a finding. Unknown type owners, package/module evidence, open variants,
unsupported classes, and exhausted bounds (128 type steps/32 module steps) are
nonwaivable undecided. Locations retain compiler source origins, including included
signatures. The gate does not reconstruct erased private layouts from implementations
or invent domain schemas/checks from protocol strings.

## Owned raw seams

The finite inventory preserves actual protocol and serialization boundaries:
Chat codecs; SystemOne state/instructions/criteria and codec functions; realtime
raw events/send/decode; OpenRouter provider schema and owned codecs; application
configuration codec callbacks; JSON logging; HTTP JSON response; and transport
serialization. The implementation matches exact published declaration identities
and requires their audited provider evidence. It never exempts every use of
Ox_json.t, a containing module, or a copied/renamed wrapper function.

A new declaration or raw field does not inherit another declaration's permission.
A protocol that has no domain designation remains ordinary protocol code; naming
it Json or decode does not itself bring it into this rule. No source/domain migration
is justified by the audited inventory, and no hypothetical user schema is fabricated.

## Regression horizon

The paired specimens are a genuine nested Dune project. The normal harness compiles
only its authored inputs afresh in scratch against declared candidate public installed
packages; the root scan records nested-project, not an exempt built fixture library.
Their exact finding/undecided line sets cover genuine validated aliases and deliberate
extensions, non-designated JSON, raw nested/aliased/substituted/callback/row positions,
recursion, Obj, renamed codecs, abstract unknowns, same-name impostors and invalid
markers.
The installed control runs the installed scanner/assets/provider metadata from an
independent /var/tmp consumer, checks explicit --self-check --root stdout, and
exercises missing/stale consumer evidence. A genuine AST-mapping compiler PPX removes
an authored marker while retaining its raw publication; the installed codec rule must
report the unmatched marker as nonwaivable undecided. It also compiles the selected signatures
of all five current PPX providers, preserving the genuine included declaration UIDs
rather than redeclaring their codecs or inventing wire schemas. Unselected public
values are shadowed with unit, never granted raw-position permission.
Independent installed-provider controls
copy the real provider outside the checkout and reject missing/malformed CMTs,
changed emitted-input digests, compiler-side PPX, missing self-import fingerprints,
changed implementation-only imports, and forged private/public package owners.
Restoring the genuine provider must restore the clean decision. Existing runtime
codec rejection/roundtrip, URL, histogram and timestamp tests remain controls, not
static validation proofs.
